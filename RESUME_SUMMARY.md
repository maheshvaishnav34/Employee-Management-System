## 🚀 Option 2: Key Highlights & Core Contributions (Highly Recommended for bullet points)
* **Architecture & Backend:** Engineered a secure, scalable RESTful API using Node.js and Express.js, integrating Mongoose schemas to manage complex relational-like data structures in MongoDB.
* **Real-time Notifications:** Implemented real-time status updates using Server-Sent Events (SSE) with an automated polling fallback mechanism to ensure consistent data delivery for high-priority updates.
* **Authentication & Authorization:** Enforced Role-Based Access Control (RBAC) across multiple authorization levels (Admin, HR, Manager, Employee) using JSON Web Tokens (JWT) for secure session management and `bcryptjs` for password hashing.
* **Core Modules Developed:**
  * **Attendance & Regularization:** Built a system tracking clock-in/out, automated working hours calculation, and an attendance regularization request workflow.
  * **Leave Management:** Enabled employees to request leaves with real-time status updates and automated manager-approval routing.
  * **Task & Performance Management:** Built a task delegation board to assign and track tasks with deadlines, alongside a performance review system for rating and feedback.
  * **Payroll Processing:** Created a dynamic payroll module to calculate base salary, bonuses, deductions, and net payouts, generating accessible digital pay slips.
  * **Recruitment Pipeline:** Developed a Candidate tracking system to manage job applicants, resumes, and interview schedules.
* **Frontend Experience:** Developed a highly responsive, modern, and interactive single-page application (SPA) using React.js (v19) and React Router, styled with custom Vanilla CSS and Lucide React icons.
